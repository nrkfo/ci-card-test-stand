# Технологическая инструкция оператора ОТК
## Ручной поиск и настройка спутниковых каналов ОТАУ ТВ (KazSat-3 58.5°E) на Smart TV

**Назначение документа:** Пошаговый регламент для операторов и контролеров ОТК на производственных линиях сборки и стендах тестирования телевизоров Smart TV (Android TV / Google TV).

---

## 1. Подготовительный этап (Физическое подключение)

1. **Спутниковый кабель (LNB IN):**
   * Подключите коаксиальный кабель от спутниковой антенны к резьбовому ВЧ-гнезду с маркировкой **«SATELLITE»** / **«LNB IN» (13V/18V)** на задней панели телевизора.
   * Плотно закрутите F-коннектор вручную без перекосов.
2. **CAM-модуль ОТАУ ТВ (DVB-CI / CI+):**
   * Вставьте тестовый CAM-модуль ОТАУ ТВ с тестовой смарт-картой в слот **COMMON INTERFACE** телевизора до характерного щелчка. Модуль должен войти плотно, параллельно корпусу.
3. **Питание и включение:**
   * Включите телевизор с пульта ДУ и дождитесь полной загрузки Android TV.

---

## 2. Сводная таблица параметров настройки

| Параметр в меню ТВ | Значение для настройки | Примечание для оператора |
|---|---|---|
| **Тип источника сигнала** | **Спутник (DVB-S / DVB-S2)** | Не выбирать «Антенна» или «Кабель» |
| **Тип антенны** | **Фиксированная антенна** *(или «Один кабель»)* | Если тарелка подключена без свитча |
| **Спутник (Satellite)** | **USER-1** *(или KazSat-3 58.5°E)* | Предустановленный пользовательский спутник |
| **Статус спутника** | **Включено (Вкл)** | Спутник должен быть активен |
| **Тип LNB (Конвертер)** | **Универсальный (Universal 9750 / 10600)** | Стандартный конвертер Ku-диапазона |
| **Питание LNB** | **Вкл (13V / 18V)** | Подает питание на головку тарелки |
| **Тон 22 KHz** | **Авто** | Управление переключением поддиапазонов |
| **DiSEqC** | **Отключить (Выкл)** | Если кабель идет напрямую от одной тарелки |
| **Базовая частота (Транспондер)** | **10762 МГц** | Главная частота национального пакета |
| **Поляризация** | **Горизонтальная (H)** | Обязательно буква «H» |
| **Символьная скорость (Symbol Rate)** | **30000 kS/s (30.000 Мсимв/с)** | Стандарт вещания ОТАУ ТВ |
| **Тип модуляции / Сигнал** | **DVB-S2 / 8PSK** | Выбирается автоматически |
| **Сетевой поиск (Network Search / NIT)** | **ОТКЛЮЧИТЬ (Выкл)** | **КРИТИЧНО:** исключает мусор сторонних операторов |
| **Тип каналов для поиска** | **Все каналы (ТВ + Радио)** *(или «Только ТВ»)* | Базовый пакет: 30 каналов |

## 3. Пошаговый алгоритм настройки на пульте ДУ

### Шаг 1. Переход в меню поиска каналов
1. На пульте ДУ нажмите кнопку **«Входы» (Input / Source)** либо на главном экране откройте приложение **«LiveTV»**.
2. Если каналы ещё не настроены, на экране появится окно:  
   *«Нет доступных каналов»* -> выберите кнопку **[Настройка каналов]**.
3. *Альтернативный вход:* откройте **Настройки (шестерёнка)** -> **«Каналы и входы»** -> **«Каналы»** -> **«Поиск каналов»**.

### Шаг 2. Выбор спутникового тракта
1. В списке типов вещания (Антенна / Кабель / Спутник) выберите **«Спутник»** и нажмите **[ОК]** (центральная кнопка пульта).
2. В типе подключения выберите: **«Фиксированная антенна или DiSEqC»** -> нажмите **[ОК]**.

### Шаг 3. Конфигурация параметров LNB конвертера
1. В списке спутников выберите строку **USER-1** (или первый доступный слот).
2. Убедитесь, что статус спутника установлен в **«Вкл»**.
3. Проверьте параметры конвертера:
   * **Тип LNB:** `Универсальный` (нижняя 9750, верхняя 10600 МГц);
   * **Питание LNB:** `Вкл`;
   * **DiSEqC:** `Отключить`.

### Шаг 4. Ввод транспондера и контроль сигнала
1. Перейдите к разделу транспондеров (Частота):
   * Выставите частоту: **10762**
   * Поляризацию: **H (Горизонтальная)**
   * Скорость потока: **30000**
2. **ВНИМАНИЕ НА ИНДИКАТОРЫ ВНИЗУ ЭКРАНА:**
   * **Уровень сигнала (Strength):** должен быть **> 70%** (зеленая или синяя шкала);
   * **Качество сигнала (Quality):** должно быть **> 60%** (шкала заполнена, статус *LOCKED*).
   > **Если шкала качества 0%:** проверьте плотность подключения кабеля к разъему Satellite (LNB IN) телевизора.

### Шаг 5. Запуск поиска
1. Обязательно проверьте, чтобы пункт **«Режим поиска / Сетевой поиск»** был в положении **«Отключить»** (или «Транспондер», а не «Сеть»).  
   *(Включение сетевого поиска приводит к захвату сторонних спутниковых операторов, переполнению списка до 197 каналов и появлению черного экрана).*
2. Нажмите кнопку **[Начать поиск]** / **[Сканировать]**.
3. Дождитесь завершения сканирования (процесс занимает 5–15 секунд). На экране отобразится:  
   *«Поиск завершен. Найдено 30 каналов»*.
4. Нажмите **[Закрыть]** / **[Готово]** для сохранения каналов в энергонезависимую память ТВ.

## 4. Контрольная верификация работы (ОТК чек-лист)

| № | Действие контролера ОТК | Ожидаемый результат | Статус |
|---|---|---|---|
| **1** | Запустить вещание первого канала из списка (*Qazaqstan HD* или *Хабар 24*) | На экране стабильное четкое изображение без артефактов и рассыпания | **PASS** |
| **2** | Проверить платный кодированный канал (*Сетанта* / *Кинохит*) | Канал открывается тестовым CAM-модулем без ошибки «Слот заблокирован» | **PASS** |
| **3** | Кнопками громкости пульта поднять звук до уровня **70%** | Четкий чистый звук из обоих стереодинамиков телевизора без хрипов | **PASS** |
| **4** | Сверить общее количество сохраненных каналов | Ровно **30 каналов** базового пакета ОТАУ ТВ | **PASS** |

## 5. Дополнительные официальные частоты ОТАУ ТВ (для справки)

Если технологическая карта требует просканировать расширенный пакет, используйте следующие официальные частоты KazSat-3:

1. **10762 H 30000** — Базовый государственный мультиплекс (30 каналов)
2. **10803 H 30000** — Республиканские каналы
3. **10845 H 30000** — Музыкальные и региональные каналы
4. **10887 H 30000** — Фильмовый пакет ОТАУ ТВ
5. **10929 H 30000** — Спортивный пакет ОТАУ ТВ
6. **10720 H 30000** — Радиостанции и инфо-каналы
